# 서울바른내과 홈페이지 데모

Next.js App Router, TypeScript, Tailwind CSS 4로 만든 반응형 홈페이지입니다.

## 로컬 실행

```bash
npm install
npm run dev -- --port 3001
```

http://localhost:3001 에서 확인할 수 있습니다. 기존 로컬 앱과 충돌하지 않도록 3001번 포트를 사용합니다.

- `/demo1`: 현재 완성한 레퍼런스 기반 버전
- `/demo2`: Demo1 레이아웃에 서울바른 브랜드와 내과 전문 진료를 반영한 버전
- `/`: `/demo1`로 이동

두 데모의 화면 코드·스타일·콘텐츠는 각 라우트 폴더에 따로 보관합니다. `/demo2`의 기준 레이아웃은 `/demo1`이며, `/demo1` 원본은 보존했습니다.

## Demo2: Demo1 레이아웃을 유지한 서울바른 버전

사용자 피드백에 따라 새 레이아웃 실험을 되돌리고 `/demo1`의 상단 중앙 로고, 전체 배경 슬라이드, 5개 소개 항목, 6개 진료 카드, 세로 의료진 소개와 이후 13개 섹션 구성을 유지합니다. 사용자가 알려준 **내과 전문**을 중심으로 소화기 진료·건강검진·만성질환 관리 문구를 정리했습니다.

- 제공된 로고의 고해상도 복원본과 파란색을 적용합니다.
- 금색 인증 모양과 하트 장식 대신 실제 진료 범위 안내를 표시합니다.
- 의료진 소개·검진·내시경·초음파·만성질환·진료철학·수액·예방접종·시설·지도 배치는 `/demo1`과 같습니다.
- 탭의 방향키·Home·End, 슬라이드 재생 제어, 모바일 메뉴와 포커스·동작 줄이기는 기존 구현을 유지합니다.
- 의료진 성함·약력·실제 운영 정보는 확인 후 반영하며 가상의 경력을 만들지 않습니다.

화면과 동작은 `src/app/demo2/reference-experience.tsx`, 콘텐츠는 `reference-content.json`에 있습니다. `node scripts/prepare-demo2-brand.mjs`는 `/demo1`을 기준으로 `/demo2`만 재생성합니다. 이전 독립 레이아웃은 `reference-source/demo2-independent-layout/`에 보관하며 현재 페이지에서는 사용하지 않습니다. 검증 기록은 `qa/demo2-reference-layout/`에 있습니다.

### 상단·첫 화면 다듬기

첫 번째 세부 개선은 상단과 첫 화면에 한정합니다. 중앙 로고와 상단 213px, 전체 배경 슬라이드 및 이후 섹션 배치는 유지했습니다. `entry-polish.css`는 재생성 스크립트가 최종 스타일에 덧붙이므로 이 파일에서 해당 개선을 관리합니다.

| Before | After | Why |
| --- | --- | --- |
| 긴 메뉴 이름과 서로 다른 메뉴 폭 | 8개 메뉴의 짧은 이름과 같은 폭 | 탐색과 정렬 개선 |
| 첫 화면의 긴 두 줄 문구 | 내과 전문 진료와 병원 이름의 크기 구분 | 병원의 진료 성격과 이름을 먼저 전달 |
| 사진 전체를 같은 명암으로 덮음 | 글자 뒤의 명암을 유지하고 사진 가장자리를 밝게 조정 | 사진과 글자를 함께 읽기 쉽게 표현 |
| 큰 테두리 버튼 | 크기와 글자 굵기를 정리하고 누름·포커스 반응 유지 | 주 행동을 분명하게 표시 |

PC·모바일 확인, 화면 기록과 변경 범위 해시는 `qa/demo2-entry-polish/`에 있습니다. 첫 화면 아래의 HTML과 `/demo1` 파일은 변경되지 않았습니다.

### 진료 카드 스타일 변경

진료 카드 6개의 PC 3열·모바일 2열, 사진 종류와 순서, 진료 안내 연결은 유지하되 레퍼런스와 시각 표현을 다르게 변경했습니다. `care-cards.css`가 재생성된 스타일의 마지막에 추가됩니다.

| Before | After | Why |
| --- | --- | --- |
| 어두운 전체 배경 사진 위의 흰 글자 | 상단의 밝은 사진과 하단의 흰색 안내 패널 | 배치는 유지하면서 레퍼런스와 구별되는 시각 스타일 |
| 중앙의 큰 원형 + 표시 | 왼쪽 제목·설명만 표시 | 불필요한 안내 문구 없이 사진과 진료명 중심으로 구성 |
| 사진 카드가 맞붙은 구성 | 같은 3열·2열 안에서 PC 12px·모바일 8px 간격 적용 | 사진과 안내 정보를 구분하되 간격은 조밀하게 유지 |

카드 전체를 클릭하거나 키보드 Enter로 이동할 수 있습니다. 직접 확인: `/demo2#care-cards`. 현재 스타일의 화면과 검증 기록은 `qa/demo2-care-style/`, 이전 간격·타입 조정 기록은 `qa/demo2-care-cards/`에 있습니다. 카드 영역 밖의 HTML, 상단·첫 화면과 `/demo1`은 보존했습니다.

## Demo1 레퍼런스 재현

```bash
npm run typecheck
npm run build
npm start
```

삼성베스트내과의 실제 DOM·CSS를 기준으로 원본 레이아웃과 반응형 구성을 재현했습니다. 제공된 서울바른내과 로고, 새로 생성한 사진, 서울바른용 데모 문구를 적용합니다. 원본의 의료진 약력·인증·가격·전화번호는 실제 운영 정보로 사용하지 않습니다.

원본과 같은 상단 213px, 중앙 정렬 메인 슬라이드, 특장점 5개, 붙어 있는 진료 카드 6개, 의료진 소개 3개, 검진 4개 탭과 세부 프로그램 6개 탭, 내시경 5개 탭, 초음파 2열 배치, 만성질환 4개 행, 원형 진료철학·수액 안내, 예방접종 카드 6개, 장비 안내 9개, 시설 갤러리와 썸네일 20개, 지도·진료시간·전화·주차 안내를 제공합니다. 우측 고정 메뉴와 모바일 펼침 메뉴도 원본 형태를 따릅니다.

연락처·비급여항목 버튼은 안내 모달을 표시합니다. 실제 예약이나 문의는 접수하지 않습니다. 실제 연락처·주소·운영시간과 의료진 정보를 확인하기 전까지 디자인 프리뷰로 사용하세요.

## 레퍼런스 변환

`reference-source/`에 조사한 원본과 이전 디자인 백업을 보관합니다. `node scripts/prepare-reference.mjs`는 병원별 정보를 교체하고, 외부 스크립트·이벤트 속성·외부 링크를 제거해 `src/app/demo1/reference-content.json`과 레퍼런스 CSS를 생성합니다. 화면 동작은 각 데모 폴더의 `reference-experience.tsx`에서 TypeScript로 구현하며 원본 JavaScript를 실행하지 않습니다. 변환 스크립트는 `/demo1`만 대상으로 하며 `/demo2` 작업본을 덮어쓰지 않습니다.

Gmarket Sans와 Noto Sans KR 서체 및 UI 아이콘은 로컬에서 제공합니다. 이미지 경로도 모두 로컬 자산으로 연결됩니다.

## 디자인·접근성 개선

섹션 순서와 기존 레이아웃, 로고, 파란색을 유지하면서 Taste Skill로 화면을 검토하고 Impeccable·Emil 지침으로 마무리했습니다. 모바일 주요 본문 16px, 제목 자간·줄 간격, 44px 이상의 메뉴 조작 영역, 섹션 제목 구조와 이미지 설명을 보완했습니다. 모바일 빠른 메뉴는 접어서 본문을 읽을 수 있습니다.

메인 슬라이드는 일시정지·재생 및 모바일 이전·다음 버튼을 제공합니다. 키보드 포커스, 마우스 올림, 화면 밖, 비활성 브라우저 탭에서는 자동 전환을 멈춥니다. 동작 줄이기 설정에서는 자동 재생을 시작하지 않으며 사용자가 직접 재생할 수 있습니다. 검진 탭은 방향키·Home·End로 이동하고, 모바일 메뉴는 포커스를 내부에 유지하며 Escape로 닫힙니다.

검증 기록과 화면은 `qa/polish/`에 보관합니다. Impeccable 자동 컨텍스트 도구는 캐시 쓰기 제한으로 실행되지 않아 기존 코드와 브라우저에서 직접 확인했습니다. 자동 접근성 인증이나 실물 휴대폰 검증을 의미하지 않습니다.

| Before | After | Why |
| --- | --- | --- |
| 모바일 설명 12.8px, 작은 메뉴 버튼 | 주요 설명 16px, 메뉴 버튼 44px | 읽기와 터치 조작 개선 |
| 슬라이드 일시정지 조작 없음 | 재생·일시정지, 모바일 이전·다음 조작 | 내용을 읽을 시간과 직접 탐색 제공 |
| 긴 탭·메뉴 전환과 불완전한 포커스 처리 | 탭 180ms, 메뉴 220ms, 키보드 탭은 즉시 전환 | 빠른 입력에 반응하고 포커스 유지 |

## 이미지

데모1은 밝은 신도시 내과 분위기의 인물·시설·장비 사진을 built-in image_gen으로 제작·편집했습니다. 반복되던 47개 위치를 별도 사진으로 바꿔 본문·배경 60곳에 서로 다른 사진을 사용합니다. 화이트·아이보리, 밝은 우드와 파란색을 사용하며, 실제 병원이나 의료진을 나타내지 않습니다. 갤러리는 중복 없는 10장, 공간 소개는 서로 다른 9장입니다. 갤러리 썸네일은 해당 큰 사진과 연결되는 작은 웹용 파일입니다.

- 데모1 원본 PNG·웹용 WebP·최종 프롬프트: `public/images/demo1-realistic/` 및 `asset-prompts.json`
- 위치별 새 사진 47종·프롬프트·적용 위치: `public/images/demo1-unique/asset-prompts.json`
- 진료·상담 장면의 의사는 기존 `public/images/physician.png`, `physician-02.png`, `physician-03.png`를 기준으로 14장에 반영했습니다. 편집 프롬프트와 참조 파일은 `public/images/demo1-unique/doctor-identity-edits.json`에 기록했습니다.
- 의사 인물 수정 반영: `node scripts/prepare-demo1-doctor-identities.mjs`, 이후 `node scripts/prepare-demo1-photography.mjs`
- 데모1 새 파란색 심볼·벡터 로고: `public/images/demo1-brand/`
- 의료진 소개용 투명 PNG·WebP 3종과 누끼 편집 프롬프트: `public/images/demo1-realistic/cutouts/`
- 메인 사진 오버레이는 검정 74%, 바로가기는 기존 흰색 테두리 스타일이며 재생·일시정지 묶음은 제거했습니다.
- 데모1 사진 적용: `node scripts/prepare-demo1-photography.mjs`
- 데모1 이미지·갤러리·데모2 보존 검사: `node scripts/verify-demo1-photography.mjs`
- 데모2 재생성의 기준 레이아웃은 `reference-source/demo2-layout-base/`에 고정하여 데모1 변경과 분리했습니다.

데모2에서 사용하는 기존 이미지와 로고는 다음과 같습니다.

- 원본 PNG 및 웹용 WebP: `public/images/`
- 이미지별 생성 프롬프트: `public/images/asset-prompts.json`
- 로고: 사용자가 제공한 `public/images/seoul-bareun-logo.png`
- WebP 변환: `node scripts/prepare-images.mjs`
- Pretendard 글꼴 라이선스: `public/fonts/OFL.txt`

이전 버전의 Unsplash 이미지 두 장은 현재 페이지에서 사용하지 않습니다.
